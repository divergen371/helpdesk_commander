## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
HC-27 の評価で、ファイルを送信しない SHA256 照合が PII リスクを増やさずに既知マルウェアを補えると判断した。ただし VirusTotal Public API と abuse.ch の無償 API は商用利用を制限しているため、特定ベンダーを前提にせず、商用契約または自前フィードを設定できるプロバイダ非依存の実装にする。既定は無効。
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 既知マルウェアの SHA256 を照合し、一致した添付を infected として隔離する
- [x] #2 外部へ送るのは SHA256 のみで、ファイル本体を送信しない
- [x] #3 照会先は設定で差し替え可能で、商用利用可能な契約または自前フィードを前提とする。無償枠の非営利制限を満たさない限り既定で無効
- [x] #4 API 障害・タイムアウト時は既存のスキャン結果を変えない（fail-open）と記録する
- [x] #5 同一ハッシュの再照会を抑止するキャッシュがある
- [x] #6 照会結果と判定を監査ログに残す
- [x] #7 会社単位の有効/無効設定があり、無効時は外部へ一切照会しない
- [x] #8 優先順位は deny > 外部 infected > allow > clean キャッシュ > 通常スキャンで、外部 infected は allow/キャッシュで覆い隠さない
- [x] #9 既知・未知・障害・キャッシュ・無効化のテストと、契約・障害・無効化の運用手順がある
<!-- AC:END -->
