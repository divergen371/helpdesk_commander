## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
HC-27 の評価で、ファイルを送信せず SHA256 の照合だけを行う外部レピュテーションが、PII リスクを増やさずに既知マルウェアの検出力を補えると判断した。VirusTotal のハッシュ照合や MalwareBazaar などを候補に、スキャン前の照会・キャッシュ・障害時の扱いを実装する。
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 既知マルウェアの SHA256 を照合し、一致した添付を infected として隔離する
- [ ] #2 外部へ送るのは SHA256 のみで、ファイル本体を送信しない
- [ ] #3 API 障害・タイムアウト時は既存のスキャン結果を変えない（fail-open）と記録する
- [ ] #4 同一ハッシュの再照会を抑止するキャッシュがある
- [ ] #5 照会結果と判定を監査ログに残す
- [ ] #6 既知・未知・障害・キャッシュのテストと運用手順がある
- [ ] #7 会社単位の有効/無効設定があり、無効時は外部へ一切照会しない
- [ ] #8 優先順位は deny > 外部 infected > allow > clean キャッシュ > 通常スキャンで、外部 infected は allow/キャッシュで覆い隠さない
- [ ] #9 主候補は MalwareBazaar。VirusTotal は有償枠（Premium / Enterprise）が利用できる場合のみ候補にする
<!-- AC:END -->

## Definition of Done
<!-- DOD:BEGIN -->
- [ ] #1 テストが通る
- [ ] #2 ドキュメントを更新する
- [ ] #3 既存機能の回帰がない
