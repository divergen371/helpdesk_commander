## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
コーパス: priv/eval/corpus に malicious 3 件（EICAR txt / zip / pdf）と benign 7 件（txt / 空 / pdf / png / zip / json / csv）、manifest.json。実マルウェアは不使用。
ハーネス: priv/eval/run_corpus.exs が Scanner.scan/1 を実行し、検出率・誤検知率・エラー率・平均/p95 スキャン時間を算出。priv/eval/stub_scanner.sh（EICAR のみ検出、zip は unzip）で CI 用に決定的に実行、EVAL_SCANNER=real で実 clamd も利用可能。EVAL_BASELINE で基準ファイルを差し替え可能。
合格基準: priv/eval/baseline.json（検出率 95% 以上、誤検知率 5% 以下、エラー率 0、p95 2000ms 以下）。下回ると exit 1。実測は stub で検出率 100%、FP 0%、p95 約 210ms（初回コンパイル込み）。strict baseline で exit 1 を確認。
レポート: eval/detection_report.json（gitignore）に JSON を出力し、CI の job summary に表を表示。artifact に eval/ を保存。
CI: ci.yml に detection-corpus job（PR / main push）、quality-nightly.yml にも追加。summary の対象に追加。
docs: docs/EVAL_DETECTION.md にコーパス・メトリクス・基準・実 clamd での変更前後比較手順・限界を記載。QUALITY_GATES / CI_CD / ROADMAP / STATUS を更新。
検証: mix quality 451 passed（13 properties / 438 tests）、dialyzer 0、codegen OK、coveralls 82.59%、sobelow 0、依存監査 ok、eval exit 0。
