## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
mix.lock と assets/package-lock の依存は更新・監査が手動で、既知脆弱性の検知が PR 時のゲートに含まれていない。daily-report-void-ts では npm audit の警告（15 件）を別タスクとして棚卸しした。Elixir 側は `mix hex.audit`（retired）と `mix_audit`（GitHub Advisory）、assets は npm audit を使い、PR と週次で検知できるようにする。

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
実装: mix_audit を dev/test に追加。priv/ci/check_audit.exs で mix hex.audit の retired/advisory を allowlist（priv/ci/audit_allowlist.txt）と照合し、未許可・期限切れ entry は失敗、期限間近・一致しない entry は警告。CI に audit job（hex.audit / deps.audit / allowlist / npm audit --omit=dev --audit-level=high）を追加し、summary job の対象に含めた。週次は .github/workflows/security-audit.yml（毎週月曜 04:00 UTC + 手動）で同じ監査を実行する。
依存更新: 初回監査で検出した advisory のうち修正版があるものを更新（ash 3.37.3 / ash_sql 0.8.6 / ash_postgres 2.15.2 / ecto 3.14.3 / bandit 1.14.1 / phoenix_html 4.4.0 / assent 0.3.2 など）。残りは Cloak 1.1.4 の AES-CTR advisory のみで、Vault は AES.GCM のみ使用・修正版なしのため理由と review_by（2027-05-01）付きで allowlist 化。
検証: 更新後 mix quality（438 tests / dialyzer 0 / codegen check）成功。allowlist 空で audit gate が exit 1、期限切れで FAILED、通常は ok を確認。npm audit（prod）0 件。docs/QUALITY_DEPENDENCIES.md と CI_CD / QUALITY_GATES / ROADMAP を更新。
<!-- SECTION:NOTES:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
依存関係の監査を自動化した。PR と週次（毎週月曜 04:00 UTC）で mix hex.audit・mix deps.audit・npm audit（本番依存、high 以上で失敗）を実行し、priv/ci/check_audit.exs が allowlist と照合する。allowlist は理由と review_by を必須にし、期限切れは失敗、期限間近・一致しない entry は警告する。初回監査で検出した advisory のうち修正版があるものは更新（ash / ash_postgres / ecto / bandit / phoenix_html / assent など）し、Cloak の AES-CTR advisory のみ使用していない（AES.GCM のみ）ため理由付きで allowlist に残した。更新後 mix quality は 438 tests / dialyzer 0 errors で通過。手順は docs/QUALITY_DEPENDENCIES.md。
<!-- SECTION:FINAL_SUMMARY:END -->
