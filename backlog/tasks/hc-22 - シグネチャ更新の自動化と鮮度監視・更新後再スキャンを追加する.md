## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
ClamAV の検出力はシグネチャの鮮度に強く依存するが、現状は更新の自動化・鮮度監視・更新後の再スキャンがない。古いシグネチャで clean になったファイルが残り続けるため、更新運用と再検査を仕組み化する。
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 freshclam などによるシグネチャ更新を定期実行し、失敗を検知できる
- [ ] #2 シグネチャの版・日時を保存し、既定の閾値を超えたら警告またはアップロード拒否する
- [ ] #3 シグネチャ更新後に既存の clean / skipped 添付を再スキャンする
- [ ] #4 再スキャンは冪等で、件数上限と失敗時の隔離がある
- [ ] #5 更新・鮮度・再スキャンのテストと運用手順がある
<!-- AC:END -->

## Definition of Done
<!-- DOD:BEGIN -->
- [ ] #1 テストが通る
- [ ] #2 ドキュメントを更新する
- [ ] #3 既存機能の回帰がない
<!-- DOD:END -->
