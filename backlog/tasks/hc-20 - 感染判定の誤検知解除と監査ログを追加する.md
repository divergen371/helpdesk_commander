<!-- SECTION:DESCRIPTION:BEGIN -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
実装: Attachments.can_override_infected?/2 と Attachments.override_infected/3 を追加。scan_status == "infected" の添付に対して、同一会社の admin または leader のみ解除可能とし、それ以外は {:error, :forbidden}（infected 以外は {:error, :not_infected}）。理由は String.trim 後に空なら {:error, :reason_required}。
解除時は Storage.promote/1 で quarantine/ -> clean/ へ移動し、scan_status を "clean"、scan_note を "false_positive_override: <reason> / previous: <prev_note>" に更新。
監査イベントとして TicketEvent（event_type: "attachment_quarantine_overridden"）を作成し、actor_id / ticket_id / company_id と data（attachment_id, filename, sha256, reason, from_status, to_status, previous_scan_note, scan_engine, scan_version）を保存。
UI: TicketLive.Show に理由入力 +「誤検知として解除」フォーム（#override-attachment-form-<id>）とイベントログの「感染判定の誤検知解除」表示を追加。
テスト: AttachmentsTest に 2 件（admin/leader による解除と TicketEvent 検証、member/customer/他社 admin 拒否・空白理由拒否・clean 添付拒否）、AttachmentLiveTest に 1 件（member 非表示・空白理由エラー・admin による解除とイベントログ表示）を追加。
検証: mix precommit 422 passed（13 properties / 409 tests）、coveralls 82.6%（3580 / 4334 行）、dialyzer 0 errors、ash.codegen --check 成功。docs/DESIGN_ATTACHMENTS.md 等を更新。
