## Description

関連リンクは手動登録のみ。件名や本文の類似から関連・重複候補を提示できるようにする。

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. 文字2-gram（日本語）と英数字単語の重み付きコサイン類似度を実装し、しきい値0.30・最大5件を既定にする。2. チケット詳細で関連候補と類似度を表示し、既リンクは除外する。3. 自動リンクはせず、候補の「関連付ける」操作でのみ related リンクを作成する。4. 類似度・テナント境界・自動リンクしないことをテストする。5. 方式としきい値を docs に記録する。
<!-- SECTION:PLAN:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
実装: TicketSimilarity を追加。NFKC正規化・小文字化のあと、日本語は文字2-gram、英数字は単語トークンにし、件名を本文の3倍で重み付けしたコサイン類似度で候補を算出する。既定しきい値0.30、最大5件、直近200件を対象。チケット詳細の「関連チケット」に類似度付きの候補を表示し、既リンクは除外する。自動リンクは行わず、「関連付ける」クリック時だけ related リンクを作成する。外部ユーザーには候補を出さない。方式・しきい値・確認手順を docs/DESIGN_TICKET_RELATIONS.md に追記した。LiquidAI D1 は HC-13 の評価が済むまで使わない。
検証: ticket_similarity_test 6 passed、ticket_similarity_live_test 3 passed、mix precommit 281 passed（13 properties / 268 tests）、coveralls 83.3%（2443 / 2932 行）、dialyzer 0 errors、ash.codegen --check 成功。
