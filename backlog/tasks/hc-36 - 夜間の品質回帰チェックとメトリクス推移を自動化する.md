## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
PR 時のゲートだけでは、依存の更新・時間経過・プロパティテストの seed 差で品質が静かに落ちる。夜間（または週次）にフル検証を回し、カバレッジ・テスト数・警告数を記録して前回比の劣化を検知する。ROADMAP の「自動で品質を高める仕組み」の中核。
<!-- SECTION:DESCRIPTION:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
実装: priv/ci/quality_metrics.exs（cover/excoveralls.json のカバレッジと TEST_COUNT を priv/ci/quality_baseline.json と比較。カバレッジ -0.3pt 超またはテスト数減少で失敗、現在値を quality-metrics.json に出力）と baseline（coverage 82.0 / tests 425）を追加。
夜間: .github/workflows/quality-nightly.yml（毎日 03:00 UTC + 手動）。テスト件数記録、format、credo strict、ash.codegen --check、coveralls.json、カバレッジラチェット、品質メトリクス、dialyzer、hex/deps 監査、npm audit を実行し、quality-metrics.json / test_output.log / cover/ を artifact に保存、job summary に metrics を表示。
検証: ローカルで TEST_COUNT=425 は ok、TEST_COUNT=100 は exit 1。docs/QUALITY_GATES.md・CI_CD.md・ROADMAP を更新。
<!-- SECTION:NOTES:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
夜間の品質回帰チェックを追加した。毎日 03:00 UTC の quality-nightly ワークフローがテスト件数・format・credo・codegen・カバレッジ・ダイアライザ・依存監査・npm audit を実行し、カバレッジとテスト数を priv/ci/quality_baseline.json（82.0% / 425 tests）と比較する。カバレッジが 0.3pt 超低下するかテスト数が減ると失敗し、quality-metrics.json とログを artifact に残す。ローカルで TEST_COUNT を変えて合格・失敗の両方を確認した。
